# 上传到 GitHub

本目录内容就是仓库根目录。上传时请上传本目录中的文件和子目录，不要只上传 pet/，也不要再多套一层 HJJ-GitHub-Upload 文件夹。不要上传 Python 自动生成的 scripts/__pycache__/ 或 .pyc 文件；使用 Git 时它们会被 .gitignore 忽略。

1. 打开你的仓库：[OldShuxi66/HJJ-](https://github.com/OldShuxi66/HJJ-)。
2. 选择 **Add file → Upload files**。
3. 将本目录中的内容拖入上传区，确认 README、两个许可证、第三方署名、安装脚本、源码和 pet/hjj/ 都在提交列表中，并排除 scripts/__pycache__/ 与 .pyc 文件。
4. 检查差异后，填写提交说明并提交到默认分支。

公开仓库中的文件会对所有人可见。提交前请确认自己有权公开 HJJ 美术和相关角色素材，并保留 Nai-wa 的上游署名及许可文件。

想让朋友直接推送修改，可在仓库 **Settings → Collaborators** 中邀请他们；否则朋友也可以通过 Fork 和 Pull Request 贡献。
